# myexporter.koplugin — KOReader 导出高亮（自制版）

一个 KOReader 的"导出高亮"插件，基于内置 exporter 插件精简改造，只保留 **My Clippings** 和 **纸间书摘（XMNote）** 两种导出目标，并给 My Clippings 增加了仿 Kindle 的**固定位置编号（#N）**。

## 特性

- **固定位置编号**：每条标注/笔记导出时带有 `位置 #218-218` 这样的编号。它基于文本内容计算，**不随字号、行距、排版变化**，同一本书永远同一个数（原理见下文）
- **中文页眉**：写死的中文格式，不受翻译文件影响：
  ```
  - 您在第 29 页（位置 #218-218）的标注 | 添加于 2026年8月29日星期六 15:01:15
  - 您在第 29 页（位置 #218）的笔记 | 添加于 2026年8月29日星期六 15:01:24
  ```
- **覆盖写入**：导出到固定文件名（如"所有书摘.txt"）时每次整体重写，不会像原版那样反复叠加产生重复内容
- **结果缓存**：位置编号算一次就存进书籍 sidecar，之后导出无需再打开文档，瞬间完成
- 保留原插件的其余能力：导出当前书 / 导出历史全部、按高亮样式和颜色过滤、自定义文件名和导出目录、纸间书摘 API 导出

## 安装

1. 下载本仓库（Code → Download ZIP），解压后把文件夹重命名为 `myexporter.koplugin`
2. 放入 KOReader 的 `plugins/` 目录：
   ```
   koreader/plugins/myexporter.koplugin/
   ```
3. 重启 KOReader
4. 建议：在 菜单 → 工具 → 插件管理 中**禁用内置的"Export highlights / 导出高亮"**，避免两套导出菜单并存

## 使用

1. 阅读菜单 → 工具 → **导出高亮（自制）** → 选择格式和服务商 → 勾选 MyClippings 和/或 XMNote
2. "导出当前书籍的所有笔记" 或 "导出历史记录中所有书籍的所有笔记"
3. XMNote 需按其菜单内的 Help 说明配置手机 IP（与原版一致）

## 位置编号（#N）是怎么算的

Kindle 的"位置"是把全书正文当作一条连续文本流，**每 128 字节算 1 个位置**，与排版无关。本插件用同样的思路：

1. 每条划线在 KOReader 里都存有 XPointer 文本锚点（指向"第几章第几段第几个字"，与排版无关）
2. 导出时用 KOReader 的文本接口量出"文档开头到这条划线之间"的字节数
3. `位置 = 字节数 ÷ 128`，高亮显示范围 `#起-止`，笔记显示单点 `#N`
4. 结果以划线锚点为键缓存进书籍 sidecar，之后直接查表

**说明与限制：**

- 编号与 KOReader 自身排版完全解耦，永久稳定
- **不保证与 Kindle 设备上同一本书的数字完全一致**（两家解析正文的字节流不可能逐字节相同），量级和稳定性一致
- 仅对 EPUB/MOBI/TXT 等文字流格式生效；**PDF/扫描版没有文本流，自动只显示页码**
- 首次"导出历史全部"需逐本打开建缓存，会慢一些，每本书只慢一次

## 目录结构

```
myexporter.koplugin/
├── _meta.lua                  # 插件元信息
├── main.lua                   # 入口：菜单、导出调度
└── myexporter/                # 内部模块（带唯一前缀，避免与其他插件冲突）
    ├── base.lua               # 导出目标基类
    ├── clip.lua               # 标注解析 + 位置编号计算与缓存
    └── target/
        ├── my_clippings.lua   # My Clippings (.txt)
        └── xmnote.lua         # 纸间书摘 API
```
